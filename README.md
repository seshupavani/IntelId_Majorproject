# ✈️ IntelId - AI Travel Iternary

An AI-powered travel recommendation platform that analyzes user travel queries and provides intelligent transportation suggestions, booking assistance, hotel recommendations, route analysis, and travel insights in real time.

The system processes natural language travel requests such as:

```text
"I travel from Bachupally to Hitech City"
```

or

```text
"I travel from Hyderabad to Tirupati"
```

and generates smart recommendations like booking a cab, flight suggestions, hotel availability, travel risk analysis, and route-based decision support.
